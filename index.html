《春灯闭园以后》
玩家调查攻略

我按实际调查思路整理，不把它写成“点这里—输密码—下一页”的流水账。这个游戏真正需要做的是：把二十年前的旧网页、冲印照片、论坛回帖、游客服务记录、工程旧机、城建档案和二十年后的拆除材料拼成同一件事。

以下内容严重剧透
新闻 旧站与照片 论坛 游客服务 工程组 城建档案 图纸 施工发现 结局

01 / 2026先从“水壶”开始，不要先找后台

开局新闻已经把调查范围限定得很清楚：2026 年拆除春灯游乐园旧址时，在魔镜宫后侧的封闭结构区发现刻有“沈荞”名字的旧水壶，2006 年的失踪案因此重新核查。

沈荞，2006 年 8 月 19 日在春灯游乐园失踪，当年 11 岁。
当年的临时员工唐屿曾承认带她走过魔镜宫侧面的员工通道。
警方当年没有认定唐屿涉案，但旧报道、论坛和后来回忆长期把怀疑集中在他身上。

继续看“水壶之后”的报道，页面会明确提示：2006 年春灯游乐园官网还有部分历史存档，其中游客相册、失物招领、暴雨当天项目通知保留了原始更新时间。

新闻报道 → 春灯游乐园 2006 历史站
我这里建议先别急着给唐屿定性。新闻里最重要的一句其实是：旧园区多次改建，仅靠旧新闻无法还原她最后走过的路线。

02 / 2006 WEB旧站、游客照片与冲印批次

进入春灯旧站后，优先翻与 8 月 19 日有关的页面：当天活动/停运信息、游客相册、失物记录。照片不是为了认“凶手”，而是为了确认谁在什么时间、什么位置真实出现过。

相册线索会把你带到旧冲印登记。需要从登记批次里找出 2006 年 8 月 19 日春灯相关的那一批。

冲印批次答案 SG-060819-087

只有这一批仍保留 8 张公开低清样片。

这组照片的作用是纠正“所有人都在可靠回忆”的错觉。后面你会看到，证人的记忆、当年的媒体说法和真正的排班/记录并不完全一致。

03 / FORUM城西生活网：真正重要的是“旧事旧人”

论坛里有大量很像真实县城论坛的闲聊，不要把每条都当谜题。主线需要看的主要是两类帖子：

失踪案旧帖

用来对照当年的流言、目击说法以及唐屿为何长期被怀疑。

旧事旧人

重点找游客中心员工陆婕的签名、工号和入职时间。相邻回复把账号信息拆开了。

游客服务系统的用户名规则是“2 位岗位代码 + 3 位工号”，初始口令是“入职年月”。把论坛里的两条信息拼起来：

游客服务系统登录答案
用户名KF017
初始口令200407
后面的 2026 采访会再次推翻陆婕过去非常肯定的说法：重新核对排班后，她发现案发傍晚其实在北门退票，因此“亲眼见过黄色雨衣”的记忆并不能可靠对应 8 月 19 日。

04 / SERVICE_DB游客服务中心：别只搜沈荞的名字

登录后是一个 2006 年游客服务中心内部只读系统。页面很多：排班、客诉、失物、退票、天气/急救、交班便笺。

这一段的核心并不是找到一条“沈荞失踪真相”，而是交叉验证：

谁在案发当晚实际值什么班；
暴雨造成了哪些停运、退票、急救和后场异常；
游客中心把哪些问题转给了工程组；
当年的公开说法里有哪些记忆其实与排班、票务记录冲突。

游客服务的转办摘要会把调查方向从“人物证词”推到工程分区。这时进入工程组旧机备份才是主线。

游客服务记录 → 工程转办 → C 区 / 魔镜宫后场

05 / ENG-03工程组旧机：C-MIRROR 才是关键目录

工程旧机按设备区域存文件，不按事故或人名归档。主页已经提醒玩家：要根据游客服务留下的工程分区去找“现场复核”。

目录中最重要的是：

C-MIRROR / 魔镜宫 · 后场 · 侧门

继续看相关维修/后场资料，会发现 C 区并不是简单的一堵墙，而是经历过改造。纸质工程附件背面还抄着城建档案的三段索引。

档案三段索引
年度段03
流水段441
分册C

组合成完整档号：

CH-03-441-C

06 / ARCHIVE城建档案：2003 年 C 区改造

进入城建档案查询，把上一段的三段索引分别放回年度、流水、分册：

03 + 441 + C → CH-03-441-C

正确卷宗题名是《春灯游乐园 C 区排水与后场检修改造》，年度 2003。

工程目录里特别值得注意的项目：

2003-04-11施工联系单 07：后场局部构造调整。
2003-05-03竣工说明：最终表达按变更联系单执行。
2003-05-03竣工平面图：最终墙体、门洞和设备位置。

关联档案还给了两张对照图：1999 原始建筑总图、2006 消防备案总图。真正的谜题从这里开始。

07 / MAP CHECK图纸题：不要读尺寸，只看“消失的结构”

这题最容易因为图纸信息多而看花。系统其实已经把任务缩得很小：

只看“后场疏散通道”上方。
2003 竣工图和 2006 消防图已经按同一比例对齐。尺寸、排水管、房间名称全部不用管。

正确操作顺序：

  1. 至少打开一次 2003 竣工图；
  2. 再打开一次 2006 消防图；
  3. 拖动一次下方对照分界线；
  4. 找出 2003 有、2006 没有的局部结构；
  5. 切回 2003 图，直接点在那块结构上并提交。
具体该点哪里

点“后场疏散通道”上方、2003 图中带斜线并标着 V-02 的小区域。

如果再回看 1999 图，还能确认这块结构并不是原建筑自带，而是后来改造出现的。

08 / 2026 SITE施工发现：二十年前那些“说不通的话”终于对上

进入住建部门的春灯拆除项目。C 区已经因为历史结构核查暂停机械拆除。

施工发现页给出最终物证：

入口坍塌层后方先发现沈荞的儿童水壶；
内部较高位置随后发现鞋、书包残片、食品包装和未拆封的绿色玻璃手链；
最后发现的遗骸经 DNA 比对确认为沈荞；
湿鞋袜搭在较高管道上，地图铺在相对干燥的设备底座旁，最高积水线低于这些物品位置。

最关键的两条旧记录终于有了对应：

2006-08-20 02:40　工程值守本：C2 东侧返水管附近有断续异响，当班判断“疑似回流，继续抽排”。

唐屿被发现时　衣裤全湿、手掌和右膝擦伤，一直说“她还在里面”“里面还有一段”“她在高的地方”。

2026 年复核确认，这些描述与夹层位置、现场物品高度相符。

到这里，游戏并不是在告诉你“唐屿其实是完美英雄”。它更残酷：他当年说了最接近事实的话，但错误图纸、经验判断、怕追责和一次次“那里就是墙”的确信，把这句话压了下去。

09 / FINALE补充公开材料与真正的结尾

施工发现页最后会进入家属同意公开的补充材料。这里已经没有需要破解的大谜题，主要是把人物关系收回来。

遗物中包括绿色玻璃手链、两张受潮的游乐园兑奖票，以及折得很小的园区地图。兑奖记录显示：

18:24
儿童游客用剩余游戏券兑换绿色玻璃手链一条。摊位员工备注：她说要送姐姐，差两张券，工作人员补了。

这和沈栀第一次笔录里“姐妹最后一次说话时正在吵架”形成了整部作品最后最难受的一次对照。

继续阅读唐屿留下的信 / 夹层里的东西 / 沈栀的留言即可看完整结局。
